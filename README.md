# دوامي — الإصدار 19.1

نسخة تطوير مستقلة من Monzer v18 لمتابعة الحضور والانصراف والإجازات والورديات والإضافي والتقارير.

## الملفات المطلوبة للنشر

ارفع **محتويات هذا المجلد كلها** إلى مجلد النشر نفسه على GitHub Pages:

- `index.html` — التطبيق، واجهته ومنطقه في ملف HTML واحد.
- `sw.js` — Service Worker للتشغيل دون اتصال بعد أول زيارة عبر HTTPS.
- `manifest.webmanifest` — تعريف التطبيق القابل للتثبيت.
- مجلد `icons/` — شعار SVG وأيقونتا PNG بمقاسي 192 و512.

لا ترفع `index.html` وحده إذا أردت التثبيت كـ PWA أو العمل دون اتصال.

## الحفاظ على بيانات الإصدار السابق

احتُفظ بمفتاح التخزين نفسه `monzer_app_v14` وبمخطط بيانات متوافق مع v18؛ لذلك تُقرأ البيانات الموجودة تلقائياً عند فتح الإصدار الجديد **في المتصفح نفسه وعلى الأصل نفسه** (البروتوكول والمضيف والمنفذ نفسيهما). إذا غيّرت النطاق أو انتقلت إلى أصل مختلف، صدّر نسخة JSON من إعدادات v18 ثم استوردها من إعدادات v19. يظل التصدير الاحتياطي موصى به قبل أي تحديث.

البيانات محفوظة محلياً في المتصفح، وليست مشفرة أو متزامنة مع خادم. التخزين المحلي قد يُمسح أو يمكن لمستخدم آخر للجهاز الوصول إليه.

## التحديثات والتشغيل دون اتصال

يستخدم `sw.js` مخبأ v19.1 ويضمّن الصفحة والـ manifest والأيقونات في حزمة التشغيل. عند إصدار تحديث لاحق، غيّر قيمة `CACHE_NAME` إلى اسم جديد. عند التفعيل، يحذف عامل الخدمة مخابئ التطبيق القديمة ذات بادئة `monzer-pwa-` أو `duwami-pwa-` فقط؛ ولا يحذف بيانات التطبيق من `localStorage`.

يلزم HTTPS لتسجيل Service Worker وتثبيت PWA؛ افتح الرابط مرة بالإنترنت وانتظر ظهور تأكيد أن ملفات التشغيل دون اتصال جاهزة، ثم أعد فتح التطبيق لاختباره قبل الاعتماد عليه في مكان بلا اتصال. يعيد التطبيق محاولة التسجيل عند عودة الإنترنت. لا يتضمن هذا الإصدار إشعارات مجدولة تعمل والتطبيق مغلقاً.

تُحفظ بيانات الدوام محلياً باستخدام `localStorage`، ولا يفترض أن يؤدي إغلاق الهاتف أو إعادة تشغيله بحد ذاته إلى حذفها. أضفنا في إعدادات التطبيق زر **«طلب حماية التخزين من المتصفح»**؛ يطلب من المتصفح استثناء بيانات الموقع من الإخلاء التلقائي، لكن القرار للمتصفح وقد يرفض الطلب. حتى عند الموافقة، لا يستطيع التطبيق منع المستخدم أو النظام من حذف بيانات الموقع يدوياً، أو إزالة التطبيق/المتصفح، أو فقدان بيانات التصفح الخاص. لذلك صدّر نسخة JSON احتياطية بانتظام، واحتفظ بعنوان النشر نفسه كي تبقى البيانات ضمن الأصل نفسه.

بعد إعادة تشغيل الهاتف، افتح أيقونة التطبيق بعد عودة النظام. يجب أن يعمل الغلاف المحفوظ دون إنترنت ما دامت بيانات الموقع وملفات Cache Storage لم تُمسح، وكان التثبيت الأول قد اكتمل بنجاح على HTTPS. لا يمكن لصفحة ويب ضمان سلوك كل جهاز أو منع حذف بياناته؛ اختبر التطبيق على الهاتف والمتصفح المستهدفين.

## ما الجديد في v19

- الاسم الجديد «دوامي» وهوية بصرية وأيقونات موحّدة للتطبيق وشريط التنقل.
- ملخص شهري محلي يبيّن السجلات المكتملة والجزئية، مع أمثلة السجلات التي تحتاج مراجعة؛ لا تُعدّل السجلات ولا تستنتج الغياب تلقائياً.
- سؤال محلي جديد عن سجلات الحضور غير المكتملة.
- تخطيط تنقل أوضح على الشاشات الصغيرة، مع الحفاظ على الوضع الفاتح والداكن.

المساعد الحالي يطابق الأسئلة مع قواعد محلية وسجلات الجهاز؛ لا يستخدم نموذج ذكاء اصطناعي أو اتصالاً خارجياً. لم تتغير معادلات الأجور والضرائب في هذا الإصدار.
